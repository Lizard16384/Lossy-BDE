# Lossy-BDE

A basic script for lossy compression of block display models. Specifically intended for exported models from block display engine.

- Lossily compresses block displays according to a global tolerance on how accurate each block can be from its exact position.

Note that this script has been unoptimized and thrown together to work as a demonstration for [Payload](https://github.com/Lizard16384/Payload). I may return to it and make it more usable some time in the future when it becomes necessary.
